Vue d'ensemble

Le FormBuilder est une refonte complète du système de génération de formulaires pour le builder Symfony. Il remplace l'ancienne approche basée sur la concaténation de chaînes de caractères par une API fluide, moderne et maintenable.

Objectifs

  • ✅ Lisibilité - Code plus clair et structuré
  • ✅ Maintenabilité - Moins d'erreurs, plus facile à modifier
  • ✅ Fonctionnalités - Champs répétables dynamiques, validation, layouts avancés
  • ✅ DX - Meilleure expérience développeur avec autocomplétion

Avant / Après

Exemple 1 : Élément simple (Titre)

❌ Avant (ElementForm)

form: `<div>
    ${form.select('fullwidth', 'Pleine largeur', {false: 'Non', true: 'Oui'}, true)}
    ${form.select('alignment', 'Alignement', {start: 'Gauche', center: 'Centre', end: 'Droite'}, true)}
    ${form.select('type', 'Type', {h1: 'H1', h2: 'H2', h3: 'H3', h4: 'H4', h5: 'H5', h6: 'H6'}, true)}
    ${form.select('styletitle', 'Style Hn', {h1: 'H1', h2: 'H2', h3: 'H3', h4: 'H4', h5: 'H5', h6: 'H6'}, true)}
    ${form.text('title', 'Titre', false)}
    ${form.select('color', 'Couleur', {primary: 'Defaut', body: 'Noir'}, true)}
    ${form.select('subline', 'Souligné', {false: 'Non', true: 'Oui'}, true)}
</div>`

✅ Après (FormBuilder)

form: new FormBuilder(builderData)
    .row()
        .addSelect('fullwidth', 'Pleine largeur', {false: 'Non', true: 'Oui'}, {required: true})
        .addSelect('alignment', 'Alignement', {start: 'Gauche', center: 'Centre', end: 'Droite'}, {required: true})
    .endRow()
    .row()
        .addSelect('type', 'Type', {h1: 'H1', h2: 'H2', h3: 'H3', h4: 'H4', h5: 'H5', h6: 'H6'}, {required: true})
        .addSelect('styletitle', 'Style Hn', {h1: 'H1', h2: 'H2', h3: 'H3', h4: 'H4', h5: 'H5', h6: 'H6'}, {required: true})
    .endRow()
    .addText('title', 'Titre', {span: 2})
    .row()
        .addSelect('color', 'Couleur', {primary: 'Defaut', body: 'Noir'}, {required: true})
        .addSelect('subline', 'Souligné', {false: 'Non', true: 'Oui'}, {required: true})
    .endRow()
    .render()

Fonctionnalités

1. Layout Management

Grille automatique 2 colonnes, rows manuels, span (pleine largeur), fieldsets.

2. Types de champs

Méthode Description Span par défaut
addText() Input texte 1
addNumber() Input nombre 1
addTextarea() Zone de texte 2
addSelect() Liste déroulante 1
addCKEditor() Éditeur riche 2
addImage() Upload d'image 2
addUrl() Input URL 1
addIconPicker() Sélecteur d'icône 1
addTable() Tableau 2
addHelp() Texte d'aide 2

3. Champs répétables dynamiques ⭐

.addRepeatable('items', {
    label: 'Item',
    min: 1,
    max: 10,
    initial: 2,
    addButtonText: '+ Ajouter',
    removeButtonText: 'Supprimer',
    template: (index, builder) => builder
        .addText(`item_${index}_title`, 'Titre')
})
