## INSTALLATION

- yarn install
- composer install
- php bin/console d:m:m
- yarn encore dev / production
- php bin/console ckeditor:install --tag=4.6.0
- php bin/console assets:install --symlink --relative

- Download Divarea plugins : https://ckeditor.com/cke4/addon/divarea
- and copy to fosckeditor/plugins/
- Add to config.js : config.extraPlugins = 'divarea';
